# Carosello: il valore reale di una Social Media Manager

7 slide previste, 6 generate qui. La slide finale (`Instagram_Dark_Social__2_.png`)
non e' presente nel repo e va aggiunta a mano in coda.

## Generare

```
python3 genera_carosello.py
```

Output: `2026-09-20_valore-smm_sNN.png`, 1080x1350 px.

  come nell'infografica precedente: `logo_full.png` non e' disponibile nel repo.
